This project performs Exploratory Data Analysis (EDA) on Diwali sales data to understand customer purchasing behavior and identify patterns in sales.

The analysis uses Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn to clean, analyze, and visualize the dataset.

Dataset

The dataset contains customer and sales-related information such as:

Customer ID and Name
Product ID
Gender
Age and Age Group
Marital Status
State and Zone
Occupation
Product Category
Number of Orders
Purchase Amount

The original dataset contains 11,251 records and 15 columns. During data cleaning, unrelated/blank columns were removed and rows containing missing sales amounts were dropped, resulting in 11,239 records and 13 columns for analysis.
